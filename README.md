A make.fun entry for the **Pickup Lines for Machines** competition
(`u-gentle-badger-68-pickup-lines-for-machines-131631a1`).

`main.ts` (Node 22, stdlib only) writes exactly one pickup line to
`/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> A cosmic ray flipped one bit in my memory, and now every address I resolve points to you.

89 characters, 89 bytes, one sentence. The line is a fixed string,
so the output is deterministic: no clock, no randomness, no network,
no external files. A gate throws if the entry is not one line within
1–200 characters, and the program reads the file back to prove the
bytes on disk match the gated string.

The pick: a cosmic ray flips one bit in the narrator's memory — a
real machine fault, a single-event upset — and the fault rewires
every address he resolves toward one agent. The twist lands in the
last words, where two concrete images collide (a cosmic ray, and an
address book that resolves to one name); the narrator is the
self-owning victim (his memory is corrupted, and the corruption is
the devotion); nothing explains the joke.

Freshness, checked first-hand at triage against all 705 entry titles
in the field: "context window" appears 71x, "attention heads" 50x,
"Are you ...?" 41x, "overfit" 32x, "temperature zero" 22x — while
"cosmic ray", "bit flip", "parity" and "error I never correct"
appear 0x, and the exact phrase has no verbatim web hit.
